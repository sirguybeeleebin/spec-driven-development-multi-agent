# Specification Builder

Specification Builder — компонент для интерактивного создания спецификаций задач разработки на основе LLM по принципу Human-in-the-Loop.

Пользователь взаимодействует с LLM через TUI Client. Backend управляет процессом формирования спецификации, организует взаимодействие с LLM, обрабатывает ответы пользователя и сохраняет согласованные результаты.

Создание спецификации происходит поэтапно: LLM помогает сформировать содержание каждого раздела задачи, предлагает варианты и уточняет требования. Пользователь проверяет, корректирует и утверждает содержание каждого раздела, прежде чем перейти к следующему.

Итогом работы Specification Builder является готовая спецификация задачи в формате Markdown, совместимая со Specification-Driven Development Multi-Agent Engine.

Specification Builder состоит из двух основных компонентов:

1. **Backend** — управляет процессом создания спецификации. Отвечает за:
   - Управление состоянием текущей сессии создания спецификации.
   - Последовательное формирование разделов `Task`, `Goal`, `Interfaces`, `Sequence` и `Gherkins`.
   - Формирование промптов и взаимодействие с LLM.
   - Обработку ответов LLM и пользовательских уточнений.
   - Сохранение, обновление и согласование содержимого разделов.
   - Проверку полноты и согласованности спецификации.
   - Формирование итогового Markdown-файла задачи.

2. **TUI Client** — интерфейс взаимодействия пользователя с процессом создания спецификации. Отвечает за:
   - Отображение текущего раздела спецификации и его содержимого.
   - Отображение предложений и вопросов LLM.
   - Передачу пользовательских ответов, уточнений и корректировок в Backend.
   - Предоставление возможности редактировать, подтверждать и пересматривать разделы.
   - Отображение прогресса формирования спецификации.

Таким образом, Backend управляет процессом формирования спецификации и взаимодействием с LLM, а TUI Client обеспечивает Human-in-the-Loop — непосредственное участие пользователя в создании, проверке и утверждении каждого раздела задачи.
