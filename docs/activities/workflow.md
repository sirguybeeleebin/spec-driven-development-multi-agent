```mermaid
flowchart TD
    A([Начало]) --> B[Получить рабочий процесс и список задач]
    B --> C[Определить зависимости между задачами]
    C --> D[Отметить все задачи как ожидающие выполнения]

    D --> E[Определить задачи, готовые к выполнению]

    E --> F{Есть невыполненные задачи с неуспешными зависимостями?}
    F -->|Да| G[Перевести такие задачи в состояние ожидания]
    F -->|Нет| H[Проверить зависимости остальных задач]
    G --> H

    H --> I{Есть задачи, все зависимости которых выполнены успешно?}

    I -->|Да| J[Выбрать готовые задачи]
    J --> K[Выполнить задачи]
    K --> L[Зафиксировать успешное выполнение и результаты]
    L --> E

    I -->|Нет| M{Все задачи достигли конечного состояния?}

    M -->|Да| N[Сформировать итоговые статусы и результаты]
    M -->|Нет| O[Остановить выполнение из-за отсутствия готовых задач]

    O --> N
    N --> P([Завершение])
```
